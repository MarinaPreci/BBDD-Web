Una aplicación guarda a sus usuarios en una tabla PERSONA(dni, nss, email, nombre, telefono). El dni y el número de la Seguridad Social (nss) son únicos; el email también es único y todo usuario tiene uno; el nombre puede repetirse; el telefono es opcional.An application stores its users in a table PERSON(dni, nss, email, name, phone). The dni and the social security number (nss) are unique; the email is also unique and every user has one; the name may repeat; the phone is optional.

a) ¿Cuáles son las claves candidatas? b) Elige una clave primaria y justifícalo; ¿qué son las demás? c) Escribe la sentencia CREATE TABLE con las restricciones necesarias.a) Which are the candidate keys? b) Choose a primary key and justify it; what are the others? c) Write the CREATE TABLE statement with the necessary constraints.

Ver soluciónShow solution

a) dni, nss y email: los tres son únicos y siempre tienen valor. nombre (se repite) y telefono (puede ser nulo) no lo son.a) dni, nss and email: all three are unique and always have a value. name (it repeats) and phone (it can be null) are not.

b) Una buena opción es dni: es corto, de longitud fija y estable. nss y email serían las claves alternativas (el email, además, puede cambiar, así que es peor candidata a primaria). Si el DNI se considera un dato sensible, podría crearse un id artificial y dejar los tres como alternativas.b) A good option is dni: it's short, fixed-length and stable. nss and email would be the alternate keys (the email can also change, so it's a worse primary candidate). If the ID number is considered sensitive data, an artificial id could be created and all three left as alternates.

  nss      CHAR(12)     NOT NULL UNIQUE,

  telefono VARCHAR(15)
);

  dni      CHAR(9)      PRIMARY KEY,
  nss      CHAR(12)     NOT NULL UNIQUE,
  email    VARCHAR(100) NOT NULL UNIQUE,
  name   VARCHAR(80)  NOT NULL,
  phone VARCHAR(15)
);

  • (1) Rejected: customer 2 has rental 3; with NO ACTION a referenced primary key can't be deleted.

VERDADERO / FALSOTRUE / FALSE

Indica si cada afirmación es verdadera o falsa.State whether each statement is true or false.

  1. Una tabla puede tener varias claves candidatas, pero solo una clave primaria.
  2. A table can have several candidate keys, but only one primary key.
  3. Una clave foránea nunca puede ser nula.
  4. A foreign key can never be null.
  5. En una relación 1:N, la clave foránea se coloca en la tabla del lado «uno».
  6. In a 1:N relationship, the foreign key goes in the “one” side's table.
  7. Un atributo derivado (como la edad) se guarda como una columna más.
  8. A derived attribute (like age) is stored as one more column.
  9. Una relación N:M siempre genera una tabla nueva.
  10. An N:M relationship always generates a new table.
  11. Una tabla en 1FN cuya clave primaria es un único atributo ya está en 2FN.
  12. A 1NF table whose primary key is a single attribute is already in 2NF.
Ver soluciónShow solution
  1. Verdadero. Las candidatas que no se eligen como primaria son las claves alternativas.
  2. True. The candidates not chosen as primary are the alternate keys.
  3. Falso. Sí puede serlo (significa «sin relacionar todavía»), salvo que se declare NOT NULL. La que nunca puede ser nula es la clave primaria.
  4. False. It can be (it means “not related yet”), unless declared NOT NULL. The one that can never be null is the primary key.
  5. Falso. Va en la tabla del lado «muchos»: cada empleado guarda el departamento al que pertenece, no al revés.
  6. False. It goes in the “many” side's table: each employee stores the department they belong to, not the other way round.
  7. Falso. No se almacena: se calcula al consultar, para evitar inconsistencias (la edad cambiaría cada cumpleaños).
  8. False. It isn't stored: it's calculated when querying, to avoid inconsistencies (age would change on every birthday).
  9. Verdadero. Con las claves de las dos entidades (foráneas) y los atributos de la relación.
  10. True. With the keys of both entities (foreign) and the relationship's attributes.
  11. Verdadero. Las dependencias parciales solo pueden aparecer con claves compuestas.
  12. True. Partial dependencies can only appear with composite keys.

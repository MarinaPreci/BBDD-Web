  • IF NOT EXISTS evita el error si ya existe.

04 — Restricciones de columna04 — Column constraints

Todas juntas en una tablaAll together in one table

CREATE TABLE usuarios (
    id     BIGINT UNSIGNED AUTO_INCREMENT,
    email  VARCHAR(100) NOT NULL UNIQUE,
    edad   TINYINT UNSIGNED CHECK (edad >= 18),
    rol    VARCHAR(10) NOT NULL DEFAULT 'socio',
    PRIMARY KEY (id)
);
CREATE TABLE users (
    id     BIGINT UNSIGNED AUTO_INCREMENT,
    email  VARCHAR(100) NOT NULL UNIQUE,
    age    TINYINT UNSIGNED CHECK (age >= 18),
    role   VARCHAR(10) NOT NULL DEFAULT 'member',
    PRIMARY KEY (id)
);
  • id se numera solo: no hace falta darlo en el INSERT.
  • id numbers itself: the INSERT doesn't need to give it.
  • Sin rol en el INSERT, vale 'socio'.
  • With no role in the INSERT, it's 'member'.
  • Un email repetido da el error 1062; una edad de 15, el 3819.
  • A repeated email gives error 1062; an age of 15, error 3819.

Aquí la clave primaria va a nivel de tabla: cuando es compuesta, es la única forma.Here the primary key sits at table level: when it's composite, it's the only way.

05 — Claves ajenas05 — Foreign keys

Políticas: qué hacer con los hijosPolicies: what to do with the children

NO ACTION / RESTRICT

La operación se prohíbe si hay hijos. Es lo que pasa si no escribes nada.The operation is forbidden if there are children. It's what happens if you write nothing.

CASCADE

Se transmite: cambia la clave del padre y cambia en los hijos; se borra el padre y se borran los hijos.It's passed on: the parent's key changes and so does the children's; the parent is deleted and so are the children.

SET NULL

Los hijos quedan vivos con la clave ajena a NULL. La columna no puede ser NOT NULL.The children survive with the foreign key set to NULL. The column can't be NOT NULL.

SET DEFAULT

MySQL no lo implementa. Acepta la sintaxis pero se comporta como NO ACTION: no lo uses.MySQL doesn't implement it. It accepts the syntax but behaves like NO ACTION: don't use it.

Cada operación tiene su política: ON UPDATE CASCADE ON DELETE SET NULL. Si los hijos no tienen sentido sin el padre, CASCADE; si pueden vivir sin él, SET NULL; si borrarlo sería un error, NO ACTION.Each operation has its own policy: ON UPDATE CASCADE ON DELETE SET NULL. If the children make no sense without the parent, CASCADE; if they can live without it, SET NULL; if deleting it would be a mistake, NO ACTION.

  • REVOKE … FROM removes exactly what you say, at the level you say.

CREATE ROLE IF NOT EXISTS ikea_admin, ikea_read_only;

GRANT ikea_read_only TO 'alicia'@'localhost';
SET DEFAULT ROLE ikea_read_only TO 'alicia'@'localhost';
  • Dar los mismos permisos a veinte usuarios: se crea un rol y se asigna a los veinte.
  • Giving the same permissions to twenty users: create one role and assign it to all twenty.
  • Si mañana cambian los permisos, se cambia el rol y listo.
  • If the permissions change tomorrow, change the role and you're done.
  • La trampa: tener el rol no es usarlo. Hay que activarlo con SET ROLE o, para siempre, con SET DEFAULT ROLE.
  • The trap: having the role isn't using it. Activate it with SET ROLE or, permanently, with SET DEFAULT ROLE.
